# TypoMeter ⌨️

### Measure Your Speed. Improve Your Accuracy.

TypoMeter is a typing speed test web application built using HTML, CSS, and JavaScript. It helps users measure their typing performance through typing speed, accuracy, and a countdown timer.

## ✨ Features

- 🚀 **WPM (Words Per Minute):** Measure typing speed in words per minute.
- ⌨️ **CPM (Characters Per Minute):** Measure the number of characters typed per minute.
- 🎯 **Typing Accuracy:** Track typing accuracy.
- ⏱️ **Countdown Timer:** Complete the typing test within a time limit.
- 🔄 **Restart Test:** Restart the test and try again.
- 📊 **Result Summary:** View your performance after completing the test.
- 📱 **Responsive Design:** Use the application on different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start typing and test your speed!

## 🎯 Project Goal

The goal of TypoMeter is to provide a simple and interactive way to practice typing and measure typing performance.
